# Storm Isles · Островите на бурята

Мобилна казуална игра (iOS + Android). Капитан възстановява разрушен от буря архипелаг:
върти колелото на компаса, строи, обстрелва и ограбва островите на съперници
и насочва бури към тях.

Направена е с **Expo (React Native + TypeScript)**.

## Пусни играта на телефона си (5 минути)

1. Инсталирай **Expo Go** на телефона си (App Store / Google Play).
2. Инсталирай [Node.js](https://nodejs.org) (LTS версия) на компютъра.
3. В папката на проекта:
   ```bash
   npm install
   npx expo start
   ```
4. Сканирай QR кода от терминала:
   - **Android**: от приложението Expo Go;
   - **iPhone**: с камерата.

Телефонът и компютърът трябва да са в една Wi-Fi мрежа. Ако не са, ползвай `npx expo start --tunnel`.
Всяка промяна в кода се появява на телефона веднага.

## Как се играе

Ти управляваш времето над морето. Долу има **небе 6×6 от облачета**. Плъзни
пръст през **3 или повече съседни еднакви облака** (диагоналите се броят).
Всяка верига струва 1 енергия, а дългите вериги дават повече.

| Облак | Какво дава |
|---|---|
| ☀️ Слънце | монети веднага |
| 💨 Вятър | пълни **платната** → обираш съкровище на съперник |
| ⚡ Мълния | пълни **оръдията** → обстрелваш остров на съперник |
| 🌧️ Дъжд | пълни **дъжда** → +1 щит |

**Бурите:** верига от 6+ облака оставя **буреносен облак** на дъската.
Докосни го и бурята удря избран съперник (пробива щитовете). Колкото повече бури
трупаш, толкова по-силен е ударът (×2 за всяка), но при **4 бури наведнъж те
се обръщат срещу твоя остров**.

Всеки остров има 5 сгради × 3 нива. Завършиш ли острова, отплаваш към следващия
(тропически → ледников → вулканичен → потънал град → небесен → …).
Енергията се възстановява (1 на 10 мин, максимум 50). Докато те няма,
съперниците те нападат, а нападателите стават цели за **отмъщение** (+50%).

## Структура

```
src/game/       Правилата на играта, без UI (лесно се тестват)
  config.ts     ← ВСИЧКИ числа за баланса са тук
  board.ts      небето от облачета: вериги, падане, ново пълнене
  engine.ts     ходове, строене, атаки, обири, бури, офлайн събития
  engine.test.ts
src/art/        Векторната графика (SVG): иконите на символите, сградите (3 нива +
                повреди), сцената на острова с анимирано море, портретите на капитаните
  themes.ts     ← цветове и декор на всеки остров
src/ui/         Бутони, панели, игрален шрифт (Rubik)
src/state/      Връзка между правилата и React + записване на прогреса
src/components/ Екранни елементи (колело, остров, попъпи)
src/screens/    Главният екран
src/i18n/       Текстове: български и английски (според езика на телефона)
scripts/balance.ts  Симулатор на икономиката
```

## Команди

```bash
npm test           # тестове на правилата
npm run balance    # колко хода отнема всеки остров
npm run typecheck  # проверка на типовете
npm run lint       # проверка на кода
```

Пример за `npm run balance` с текущите числа: остров 1 ≈ 29 хода,
остров 5 ≈ 49.

## Пътна карта

**Етап 1 — прототип (готов):** небе от облачета (вериги), строене, атаки, обири,
бури, щитове, отмъщение, офлайн нападения, запис на прогреса, BG/EN.

**Етап 2 — визия:** ✅ векторна графика вместо емоджи, игрален шрифт, въртящи се
барабани, летящи монети, анимирано море. Остава: звуци и музика, анимация на
изстрела/бурята, икона и начален екран, по-късно професионален художник за
финалния стил.

**Етап 3 — пари:**
- реклами с награда („гледай реклама → 10 завъртания“) чрез AdMob;
- покупки в приложението (пакети завъртания и монети, Battle Pass) чрез RevenueCat;
- нужни са development build (`eas build`), а не Expo Go.

**Етап 4 — истински играчи:** акаунти и сървър (Supabase или Nakama), реални
съперници вместо ботове, приятели, кланове („флоти“), седмични събития.

**Етап 5 — пускане:** Apple Developer ($99/год.), Google Play ($25 еднократно),
`eas build` + `eas submit`. Политика за поверителност. Шансовете в покупките
трябва да са показани.
